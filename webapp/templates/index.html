What the sheet needs

The first row should be column headers, with one contact per row below it. The easiest way to start is a template: {# url_for('static', ...) builds the url of a file in the static folder, here public/ #} Excel template · CSV template

ColumnAccepted formats
Name Required
or First Name + Last Name
 Full name, like Jordan Rivera
Phone Number Optional
or Phone, Mobile, Cell
 Any format, like (212) 555-0101 or 212.555.0101. Without a country code, numbers are treated as US.
Email Optional
or E-mail, Email Address
 jordan@example.com
Birthday Optional
or DOB, Birth Date
 With or without a year, like Mar 15, 15-Mar, 3/15, or 03/15/2002
