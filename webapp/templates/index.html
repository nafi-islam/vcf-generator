What the sheet needs

The first row should be column headers, with one contact per row below it. The easiest way to start is a template: {# url_for('static', ...) builds the url of a file in the static folder, here public/ #} Excel template or CSV template

ColumnAccepted formats
Name Required
or First Name + Last Name
 Full name, like Nafi Islam
Phone Number Required
or Phone, Mobile, Cell
 Any format, like 123 456 7890 or (123) 456-7890. Without a country code, numbers are treated as US.
Email Optional
or E-mail, Email Address
 nafi@example.com
Birthday Optional
or DOB, Birth Date
 With or without a year, like July 15, 15-Jul, 7/15, or 07/15/2002
